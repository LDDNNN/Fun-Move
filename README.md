# כיף של תנועה: כוח הכיתה (GameGuide Studio)

אפליקציה להפעלת שיעורי תנועה של 45 דקות בכיתות א'-ג', בלחיצת כפתור.

## הפעלה

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה לפרסום (תיקיית dist)
```

- `/` הוא לוח המורה: בחירת דמות, מהלך השיעור, שליטה, כוח הכיתה, מד הצלחה ותעודה.
- `/#player` הוא הלוח החכם לילדים: מסך מלא, בלי טקסטים ניהוליים.
  "פתח לוח חכם בחלון" פותח אותו בחלון נפרד, ושני החלונות מסונכרנים.

## סרטוני אווטר (HeyGen)

שמים MP4 ב־`public/assets/<id>.mp4`. המזהים הם `samson`, `david`, `esther`, `miriam`, `devorah`, `moshe`, `yosef` ו־`ruth`.
אם אין סרטון, מוצגת דמות מונפשת והקול מגיע מהקראה בעברית של הדפדפן.
כדי שסרטון ינהל את ההדמיה בעצמו (עם הקול שלו), מוסיפים זמנים ל־`VIDEO_CUES` ב־`src/data/characters.js`.

## מבנה

- `src/data/characters.js` מכיל את `CHARACTER_MASTER_CONFIGS`: 8 הדמויות, הפקודות, הדמיון המודרך והמשחק המסכם.
- `src/engine/script.js` הוא מנוע עליית הדרגות (רמות 1-4, כל 30 הילדים פועלים יחד).
- `src/engine/useScriptRunner.js` מסנכרן בין הקול, הכתוביות, ההדמיה והספירה לאחור.
- `src/components/player/GameDemoSimulations.jsx` היא הדמיית 30 הילדים, שמגיבה לכל פקודה.

## פרטיות

אין שמירה של שמות, תמונות או ציונים של תלמידים. זיהוי הדיבור והקראה מתבצעים בדפדפן.
